# Recursos visuales

El favicon personalizado ya está incluido como `favicon.png` y enlazado en
`../index.html` mediante una ruta relativa:

```html
<link rel="icon" type="image/png" href="./assets/favicon.png">
```

Conservar este archivo al preparar el repositorio para GitHub Pages.
La ilustración del estado vacío y la marca visual son SVG integrados en el HTML.
